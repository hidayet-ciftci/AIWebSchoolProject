# Frontend — Next.js

AIWebSchoolProject frontend uygulaması. Next.js 15, React 19, TypeScript, Tailwind CSS.

Kurulum ve başlatma için proje kök dizinindeki [README.md](../README.md) dosyasına bak.

## Geliştirme

```powershell
cd frontend
npm install
npm run dev
```

Uygulama: `http://localhost:3000`

## Ortam Değişkeni

`frontend/.env.local` dosyası gereklidir:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```
